## WV-001 | Two-parameter server command without a prefix
spec: RFC 2812 section 2.3 (message format), section 3.7.2 (PING)
status: stable
utf8: relevant
why: Baseline shape for every server line the runtime parses into observed state.
input: PING :hello\r\n
expect: ok
command: PING
param: hello

## WV-002 | Prefix with nick, user, and host
spec: RFC 2812 section 2.3 (prefix), section 3.1 (prefix formats)
status: stable
utf8: relevant
why: Membership attribution depends on the prefix nick, not on free-form text.
input: :alice!user@host JOIN #room\r\n
expect: ok
prefix: alice!user@host
command: JOIN
param: #room

## WV-003 | Trailing parameter containing spaces
