## Evidence

- IRC ordinary line ceiling: 512 octets including CRLF. Tagged lines use an independent maximum 8191-octet tag prefix including `@` and separator plus a 512-octet IRC body. Directional tag-data ceiling: 4094 octets. See `architecture/irc-wire.md` and RFC 2812 / IRCv3 Message Tags references there.
- Wire suite covers maximum and maximum-plus-one framing/tag/body/count cases, tag escape and duplicate semantics, unknown commands, leading-colon parameter roundtrip, every split point, concatenated lines, oversized-line recovery, and deterministic arbitrary input with bounded decoder state.
- I2pEndpoint accepts classified I2P hostname, standard/extended Base32, and bounded Destination text forms without name resolution. Generic URLs, IP literals, host:port, controls, and overlength values are rejected.
- Virtual timers have bounded capacity, deterministic equal-deadline ordering, cancellation by drop, wakeup on advancement, and saturating deadlines.
- Scripted duplex fixtures preserve order under bounded backpressure and cover short I/O, stalls/resume, EOF/reset boundaries, peer close, bounded optional capture, local acceptor separation, and deferred-generation completion fencing.
- Boundary check `scripts/check-network-boundary.py` passed. Its forbidden-source and forbidden-dependency positive controls use the same analysis predicates as the production guard; production and build-script manifests/tree are included.
- Dependency review: `cargo tree --locked --workspace -e all`. Production network authority remains the injected I2pStreamProvider. Runtime dependencies are Tokio, base64, zeroize, and local core/wire; testkit async-trait is test-fixture infrastructure. No router/SAM, HTTP, or generic upstream connector was introduced.
- Deterministic fuzz smoke exercises 10,000 generated byte inputs with parse/encode semantic and decoder-bound assertions. This is a reproducible smoke/property check, not a coverage-guided fuzz campaign.
