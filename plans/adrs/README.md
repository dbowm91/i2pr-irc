# Architecture Decision Records

ADRs record durable architectural decisions.

Naming: ADR-NNNN-short-title.md.

Statuses: proposed, accepted, rejected, deprecated, superseded.

Accepted ADRs are historical records and are not rewritten to make a later decision appear original.

An ADR should contain context, decision drivers, considered options, decision, consequences, compatibility/migration, security/reliability implications, verification, and supersession.
