# Milestone Implementation Plans

Implementation plans are bounded handoff artifacts tied to current repository evidence.

Layout:

plans/implementation/<subsystem>/NNN-short-title.md

Each plan contains objective, readiness/dependencies, current evidence, invariants, scope, required production changes, ordered work packages, failure/restart/contention semantics, compatibility, tests, verification, documentation, acceptance criteria, stop conditions, closure evidence, and handoff notes.

Corrective work receives a new numbered plan in the same subsystem and references the failed or conditional closure.
